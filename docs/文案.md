# PLogin 文案与玩家提示汇总

> 适用于 Minecraft 26.2 / Fabric Loader 0.19.5 / Java 27。
> 实际聊天消息前缀统一为 `[PLogin]`，踢出/标题消息按代码中的颜色显示。
> 本文件同时包含：对外宣传文案、玩家提示、服主公告模板、命令说明、配置语义。

---

## 1. 对外宣传文案

### 1.1 一句话版

**PLogin：让正版和离线玩家在同一个 26.2 Fabric 服务器里共存。**

### 1.2 短版（服务器列表 / 群公告）

```
PLogin —— 26.2 Fabric 混合登录
正版玩家直接进服，离线玩家可注册；
正版玩家可设置离线备份密码，正版验证不可用时用密码进入；
登录前隔离在 limbo，不暴露真实坐标；
客户端不需要安装任何模组。
```

### 1.3 完整版

```
PLogin 是一个面向 Minecraft 26.2 Fabric 服务端的混合登录模组。

它把正版验证和离线注册放在同一套流程里：
- 正版玩家验证成功直接进入，保留正版 UUID、皮肤、披风；
- 离线玩家使用离线 UUID 注册/登录，可以正常游戏；
- 正版玩家可以额外设置“离线备份密码”，
  在正版验证不可用或自己使用离线客户端时，用同一个名字和密码进入；
- 离线备份验证通过后，服务端才踢掉同名的在线正版玩家，
  然后通过一次重连切换到正版 UUID，与正版存档共用；
- 未登录玩家被隔离在 plogin:limbo 虚空维度，不暴露主世界坐标，
  不出现在正常玩家的 Tab 列表，也不能被 /tp、/kill、/damage 影响；
- 客户端不需要安装 PLogin，只需要服务端有 Fabric API + PLogin。
```

### 1.4 特性列表

- ✅ `online-mode=true` 下混合登录
- ✅ 正版 UUID / 正版皮肤 / 披风 / 鞘翅保留
- ✅ 离线 UUID 修复（`OfflinePlayer:<name>`）
- ✅ 离线注册、登录、改密、登出
- ✅ 正版玩家设置离线备份密码
- ✅ 备份密码验证通过后才踢正版，避免误踢
- ✅ 备份登录重连后切换正版 UUID，共用正版存档
- ✅ Limbo 虚空维度，隐藏未登录玩家真实坐标
- ✅ 未登录玩家 Tab/世界隐藏，joined/left 消息不提前暴露
- ✅ 未登录玩家 /tp、/kill、/damage、死亡/重生保护
- ✅ LittleSkin + MineSkin 离线皮肤（可选）
- ✅ 客户端零模组

### 2.5 未登录玩家的系统消息规则

- 未登录期间：不广播 `xxx joined the game`；
- 未登录期间退出：不广播 `xxx left the game`；
- 登录成功后：补发 `xxx joined the game`，Tab 重新显示；
- `/logout` 后：补发 `xxx left the game`，Tab 再次隐藏；
- 正常玩家/正版玩家的 joined/left 不受影响。

## 3. 命令文案

### 玩家命令

```
/register <密码> <确认密码>    注册离线账号；正版玩家用它设置备份密码
/login <密码>                  离线登录；备份验证后重连不再需要
/logout                        离线登出
/changepassword <旧> <新>      修改离线密码

别名：/reg /l /cp
```

### 管理员命令

```
/plogin reload                         重载配置与语言
/plogin list                           已注册用户数
/plogin info <玩家>                    UUID / 类型 / 状态 / 最后登录
/plogin unregister <玩家>              删除登录记录（不删除世界存档）
/plogin resetpassword <玩家> <新密码>   重置离线密码
```

> `/plogin unregister` 只删除 `users.json` 里的登录记录，不删除正版 UUID 的
> playerdata / 世界存档；如果是正版在线玩家执行，正版登录不受影响。

## 4. 服主公告模板

### 4.1 开服公告

```
【PLogin 混合登录】
- 正版玩家直接进服，无需注册；
- 离线玩家进服后按提示 /register <密码> <确认密码>；
- 想设置离线备份密码的正版玩家，登录后执行 /register <密码> <确认密码>；
- 正版验证不可用时，可用备份密码离线进入，验证通过后会重连到正版存档；
- 未登录玩家会被隔离在 limbo，不影响主世界和正常玩家；
- 客户端不需要安装任何模组。
```

### 4.2 给正版玩家的说明

```
如果你是正版玩家：
1. 正常正版登录即可进入；
2. 建议执行 /register <密码> <确认密码> 设置离线备份密码；
3. 正版验证不可用/你自己用离线启动时，可用 /login <密码> 进入；
4. 备份密码验证通过后会踢掉在线的正版同名号，并提示你重连一次，
   重连后使用正版 UUID 和同一份存档。
```

### 4.3 给离线玩家的说明

```
离线玩家进服后：
- 第一次：/register <密码> <确认密码>
- 之后：/login <密码>
- 修改密码：/changepassword <旧密码> <新密码>
- 未登录时会被冻结在 limbo，不能移动/聊天/使用命令。
```

### 4.4 数据/安全说明

```
- 正版名字只允许正版登录；离线冒用会被拒绝；
- 正版玩家设置备份密码后，才允许离线用该名字登录；
- 备份密码是真实凭据，请使用强密码，不要与其他账号共用；
- 未登录玩家不会出现在正常玩家的 Tab/主世界中；
- 管理员仍可通过 /list 和服务器日志看到未登录连接。
```

## 5. 配置语义（给服主）

| 配置 | 说明 |
|---|---|
| `online-mode=true` | 混合登录前提 |
| `premiumBypass=true` | 正版玩家直接进入，不需要密码 |
| `premiumPasswordBackup=true` | 允许正版玩家 `/register` 设置离线备份密码 |
| `premiumNameProtection=true` | 已记录正版名禁止离线冒用；没有备份密码时离线直接拒绝 |
| `fallbackToOfflineWhenAuthServerDown=true` | 会话服务器不可用时是否按离线放行 |
| `skipClientAuthForOfflineClients=true` | 对离线 profileId 跳过客户端 joinServer，避免“无效会话” |
| `forceDisableSecureProfile=true` | 强制有效 `enforce-secure-profile=false`，避免离线聊天被踢 |
| `requireRegistration=true` | 离线玩家必须先注册 |
| `loginTimeoutSeconds` / `kickOnTimeout` | 未登录超时 / 超时踢出或切旁观 |
| `blindness` / `freezeMovement` | 未登录失明 / 冻结移动 |
| `language` | `zh_cn` / `en_us` |
| `offlineSkinsEnabled` / `offlineSkinProvider` | 离线皮肤开关/来源 |
| `offlineSkinSiteRoot` | LittleSkin 等 CustomSkinAPI 根地址 |
| `offlineSkinMineSkinSigning` / `offlineSkinMineSkinApiKey` | MineSkin 签名/Key |
| `offlineSkinAllowUnsignedFallback` | 是否允许未签名皮肤（通常只有本机可见） |

## 6. English Copy (short)

```
PLogin — hybrid authentication for Minecraft 26.2 Fabric.

Premium players join directly and keep their UUID, skin and cape.
Offline players can register and log in with /register and /login.
Premium players may set an offline backup password with /register;
if premium authentication is unavailable, they can use /login offline.
After a successful backup login, the premium session is disconnected and
the player reconnects once to switch to the premium UUID and shared save data.
Unauthenticated players are isolated in plogin:limbo, hidden from the tab list,
and cannot be teleported to, killed, or damaged.

No client mod is required.
```
